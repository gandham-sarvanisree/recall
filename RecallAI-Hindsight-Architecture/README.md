# RecallAI Relationship Intelligence with Hindsight Memory Framework

Production-grade implementation for Microsoft-focused hackathon integrating the Hindsight Memory Framework with Next.js 15, Node.js, PostgreSQL (`pgvector`), and Google Gemini 2.5 Flash / Text Embedding 004.

## Features
- **Experience Capture & Retain**: Automatic fact, entity, and commitment extraction from meetings and interactions.
- **Reflect Engine**: Automated extraction of risks, opportunities, learnings, and shifts.
- **Memory Consolidation & Vector Retrieval**: Semantic search powered by `pgvector`.
- **Relationship Graph & Timeline**: Chronological tracking of relationship evolution.
- **Authentication**: JWT-based secure user isolation.
